📤 Upload Questions via CSV, Excel, or Word

Bulk import questions using the full DOC/DOCX pipeline (normalize → equations → LaTeX → preview → import)

🔄 Question import pipeline

  1. DOC / DOCX Upload (CSV & Excel also supported)
  2. Prepare / Normalize document (OOXML fix)
  3. DOC → DOCX automatic conversion (LibreOffice, or Microsoft Word on Windows)
  4. Extract equations (OMML / MathType / images)
  5. Equation → LaTeX when OMML is available; otherwise clear equation images
  6. Parse questions + A/B/C/D
  7. Parse answer sheet
  8. Preview questions
  9. Edit if required
  10. Import Questions → existing database

Live server (Render) tip: Legacy .doc needs LibreOffice for conversion. On your Windows PC, Microsoft Word is used automatically — that is why the same file works locally. Prefer uploading .docx on live (Word → Save As → .docx), or redeploy with the Docker image that includes LibreOffice.

📋 File Format Required (CSV or Excel — same columns either way):

📥 Download Sample Excel (.xlsx) 📥 Download Sample Word (.docx)

  • question_text - The question statement
  • question_type - single_choice, multiple_choice, true_false, numerical, matching, or structured
  • option_a, option_b, option_c, option_d - Answer options
  • correct_answer - e.g., "A" or "A,B" for multiple choice
  • marks - Points for the question (default: 1)
  • explanation - Optional explanation
  • hint - Optional clue shown to students when they tap Hint during practice
  • topic, paper_code, year, season, zone, question_number - Optional for saving the question, but paper_code is required for it to show up in the Exam Builder / Build Question List tools on the admin and student panels (e.g. topic="Functions", paper_code="0606/23", year=2019, season=winter). Rows left blank are still saved and visible in Manage Questions.

📄 Word (.docx / .doc) Format Instead:

📥 Download Sample Word Question Paper (.docx)

  • Numbered questions (typed "1." or a Word auto-numbered list), each followed by (a) (b) (c) (d) options — matching the classic past-paper layout.
  • An "Answer Sheet" table/section at the end: a row of question numbers followed by a row of answer letters, repeated in blocks (e.g. 1–10, then their answers b, c, c, d...).
  • Optional per-question clue: a line like Hint: use Rolle's theorem (or Clue:) under that question. Students can open it with the Hint button.
  • Since this file doesn't have topic/paper_code/year/season/zone columns, fill in the optional fields below to apply them to every question in the file at once.
  • ✅ Equations (MS Equation Editor / MathType pictures) are imported as clear images inside the question text — no need to retype them.
  • Paper code is required for Word uploads (e.g. 0606/26) so questions appear in Exam Builder. Fill the Word batch fields below.

How this works
After upload, the file is normalized, equations are converted to LaTeX, questions and the answer sheet are parsed, then you get a preview screen where you can edit or skip questions before they are written to the database. Nothing is saved until you click Import into database on the preview page. For Exam Builder, fill Paper code (required for Word files).
⏱ Word files with math may take about 10–30 seconds while OMML formulas are converted to LaTeX. Keep the tab open — do not click Upload again. CSV/Excel without equations is usually under a few seconds.
